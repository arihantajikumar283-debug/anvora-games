How To Play

🧠 Memory

Watch which tiles light up, then click them in any order once they go dark. Grids grow and flashes get shorter as you improve.

🧩 Logic

Complete number and shape sequences by picking the value that continues the pattern.

🔢 Number Rush

Solve arithmetic before the timer runs out. Answer fast for bonus points.

🔷 Pattern

A row of shapes repeats in a cycle — figure out which shape comes next.

⚡ Reaction

Tap only the target described on screen, as fast as you can, among decoys.

🎯 Mixed Mode

All challenge types appear in random order — the ultimate high-score test.
